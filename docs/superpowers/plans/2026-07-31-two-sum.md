**Goal:** Add a tested, LeetCode-compatible Python solution for the Two Sum problem.

**Architecture:** `Solution.twoSum` scans the input once and stores numbers already seen in a dictionary that maps number to index. For each current number it returns the stored index of the required complement and the current index. Tests call the public method directly through `unittest`.

**Tech Stack:** Python 3 standard library, `unittest`, Git.

## Global Constraints

- Keep the solution compatible with LeetCode's `class Solution` format.
- Use a one-pass dictionary lookup algorithm with O(n) time and O(n) extra space.
- Do not add third-party dependencies.
- Return `[]` only when input violates the problem's exactly-one-solution guarantee.

- [ ] **Step 3: Write the minimal implementation**

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen: dict[int, int] = {}
        for index, number in enumerate(nums):
            complement = target - number
            if complement in seen:
                return [seen[complement], index]
            seen[number] = index
        return []
```
